# Client Confirmation Checklist

No item in this checklist is assumed from prototype copy. The owner must provide evidence, scope, effective date, and an accountable approver before production visibility is enabled.

## Brand and legal identity

- [ ] Public store name and approved Persian/Latin spelling
- [ ] Legal entity name
- [ ] National ID or equivalent legal identifier
- [ ] Registration number, if public display is required
- [ ] Legal representative name and authority
- [ ] Privacy contact email
- [ ] Public business address and postal code
- [ ] Permission and exact rules for displaying KRONOS branding assets

## Contact and support

- [ ] Public telephone numbers in international format
- [ ] Public support and general email addresses
- [ ] Ownership verification for each contact channel
- [ ] Support timezone
- [ ] Weekly business hours and holidays
- [ ] Any promised response-time target and its measurement process

## Shipping

- [ ] Supported destinations and excluded regions
- [ ] Shipping methods and carriers
- [ ] Dispatch cutoff and estimated delivery rules
- [ ] Shipping cost calculation
- [ ] Free-shipping threshold, currency, dates, exclusions, and checkout implementation
- [ ] Tracking availability
- [ ] Packaging and insurance wording with actual limits
- [ ] Versioned public shipping policy path

## Returns

- [ ] Whether returns are offered
- [ ] Return window and start event
- [ ] Product-condition requirements
- [ ] Non-returnable categories and exceptions
- [ ] Inspection, refund, and shipping-cost process
- [ ] Versioned public return-policy path and effective date

## Warranty and authenticity

- [ ] Warranty provider per product/SKU
- [ ] Warranty type, duration, coverage, exclusions, and claim process
- [ ] Public warranty policy path
- [ ] Authenticity evidence model per SKU
- [ ] Source-chain, inspection, reference/serial, and included-document scope
- [ ] Exact copy approved by Legal and Merchandising
- [ ] Confirmation that brand presence does not imply official representation unless authorized

## Social and trust providers

- [ ] Official URL and ownership evidence for every social profile
- [ ] Permission to display each social platform link
- [ ] Trust-provider name, verification URL, logo license, status, and evidence
- [ ] Permission to display third-party watch-brand names and logos

## Enamad

- [ ] Enamad public identifier
- [ ] Official verification URL
- [ ] Approved public logo asset
- [ ] Verified production domain
- [ ] Current status and last verification timestamp
- [ ] Confirmation that no arbitrary HTML/script is required for frontend storage

## Payment presentation

- [ ] Checkout mode: disabled, manual, or online
- [ ] Enabled provider IDs from the frontend allowlist
- [ ] Public provider display names and descriptions
- [ ] Approved public logo assets
- [ ] Supported currencies
- [ ] Display order
- [ ] Confirmation that all secrets remain server-side

## Currency and pricing display

- [ ] Authoritative transaction currency
- [ ] Public display unit, including rial/toman conversion rule
- [ ] Locale and digit preference
- [ ] Fraction-digit and grouping rules
- [ ] Tax-inclusion wording ownership

## Feature and integration readiness

- [ ] Wishlist policy
- [ ] Compare limit and policy
- [ ] Reviews and ratings backend, moderation, and schema-data source
- [ ] Newsletter provider, consent text, privacy basis, and unsubscribe flow
- [ ] Contact-form endpoint and success acknowledgement
- [ ] Authentication backend and account-security flows
- [ ] Checkout mode and order service
- [ ] Shipping-estimator source
- [ ] Return and warranty policy pages

## Production approval record

- [ ] Configuration version
- [ ] Approval date
- [ ] Approver names/roles
- [ ] Evidence references stored outside the public bundle where necessary
- [ ] Expiry/reverification dates
- [ ] Production domain and robots policy
