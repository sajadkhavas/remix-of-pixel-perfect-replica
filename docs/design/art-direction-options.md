# گزینه‌های Art Direction برای KRONOS

## معیار انتخاب

- تمایز از فروشگاه ساعت «مشکی و طلایی»
- وضوح commerce و اعتماد
- امکان اجرا در RTL
- کیفیت برابر موبایل و دسکتاپ
- هزینه performance قابل کنترل
- سازگاری با catalog چندبرندی
- امکان تولید asset در ایران بدون وابستگی به campaignهای برندها

## Direction A — Cinematic Horology

**Concept:** ساعت به‌عنوان شیء سینمایی؛ نور کنترل‌شده، macro detail و فصل‌های روایی کوتاه.  
**Emotional tone:** عمیق، آرام، دقیق، aspirational.  
**Color behavior:** زمینه‌های زغالی و ink؛ accent فلزی بسیار محدود؛ هر campaign یک tint کنترل‌شده.  
**Typography:** display محدود برای headline؛ body واضح و انسانی؛ اعداد tabular.  
**Photography:** hero سه‌بعدی/packshot با rim light، macro movement و wrist lifestyle.  
**Motion:** reveal آهسته، camera-like scale 1–2٪، crossfade؛ بدون particle/tilt grid.  
**Texture:** grain ثابت بسیار کم یا material close-up؛ نه noise متحرک.  
**Layout:** full-bleed در chapterهای محدود، بقیه grid دقیق.  
**Product presentation:** product large، negative space، CTA و قیمت ثابت/آرام.  
**Mobile:** crop اختصاصی، حذف parallax، متن کوتاه و media 4:5.  
**Strengths:** هویت قوی و premium perception.  
**Risks:** تولید asset گران؛ خطر oversize media و کندی.  
**Performance cost:** Medium–High، فقط با budgets و responsive media.  
**Accessibility:** autoplay باید کنترل شود؛ reduced motion به still composition تبدیل شود.  
**Brand fit:** مناسب homepage/editorial، نه تمام صفحات commerce.

## Direction B — Editorial Precision

**Concept:** فروشگاه مانند مجله تخصصی مدرن؛ hierarchy تایپی و تصویر factual قهرمان است.  
**Emotional tone:** مطمئن، آگاه، آرام، curated.  
**Color behavior:** graphite/porcelain با یک brass accent؛ رنگ محصول در تصویر می‌آید نه UI.  
**Typography:** Persian-first sans برای UI و editorial display کنترل‌شده؛ line length دقیق.  
**Photography:** packshot خنثی + مقاله/مواد/کارگاه؛ تصاویر کمتر اما قوی‌تر.  
**Motion:** micro-interaction کوتاه و reveal محدود؛ native scroll.  
**Texture:** کاغذ/فلز به‌شکل تصویری، بدون effect دائمی.  
**Layout:** 12-column desktop، asymmetry کنترل‌شده در editorial، grid ثابت در shop.  
**Product presentation:** specs و قیمت خوانا، gallery و comparison اولویت دارند.  
**Mobile:** single-column editorial، sticky commerce controls و touch-first.  
**Strengths:** usability، scale و performance عالی؛ مناسب marketplace چندبرندی.  
**Risks:** اگر photography ضعیف باشد ممکن است بیش از حد خنثی شود.  
**Performance cost:** Low–Medium.  
**Accessibility:** بهترین گزینه برای contrast، focus و reduced motion.  
**Brand fit:** بسیار بالا برای کل پروژه.

## Direction C — Modern Mechanical Luxury

**Concept:** الهام از geometry، bevel، brushed metal و precision engineering بدون شبیه‌سازی literal موتور ساعت.  
**Emotional tone:** فنی، معاصر، confident.  
**Color behavior:** gunmetal، warm neutral، oxidized brass، occasional cobalt برای info.  
**Typography:** grotesk دقیق + display serif محدود؛ اعداد mono/tabular.  
**Photography:** macro engineering، exploded detail فقط در content، packshot contrasty.  
**Motion:** snap/reveal کوتاه، line tracing محدود، state transitions mechanical.  
**Texture:** brushed metal/etched grid به‌صورت static و بسیار کم.  
**Layout:** modular، baseline grid، dividers دقیق و density متوسط.  
**Product presentation:** specifications و material tags برجسته‌تر.  
**Mobile:** modules stack، grid texture حذف، controls بزرگ.  
**Strengths:** هویت اختصاصی و مناسب علاقه‌مندان فنی.  
**Risks:** خطر تبدیل به dashboard یا «تم صنعتی»؛ تزئینات مکانیکی ممکن است زیاد شوند.  
**Performance cost:** Medium.  
**Accessibility:** line animation باید optional؛ texture نباید contrast را کاهش دهد.  
**Brand fit:** خوب برای product/spec/service، ضعیف‌تر برای fashion/lifestyle.

## پیشنهاد نهایی — Editorial Precision with Cinematic Chapters

**مسیر اصلی:** Direction B — Editorial Precision  
**ترکیب کنترل‌شده:** 20–25٪ از Direction A فقط در Homepage Hero، campaign و article hero؛ 10–15٪ از Direction C در specification، comparison و service evidence.

### فرمول سیستم

- **Commerce surfaces:** روشن، ثابت، سریع و کم‌حرکت.
- **Editorial chapters:** سینمایی ولی کوتاه، media-budgeted و قابل توقف.
- **Mechanical cues:** فقط برای توضیح material/movement، نه decoration عمومی.
- **Gold/brass:** punctuation، نه background یا رنگ تمام CTAها.
- **هویت:** از crop، typography، spacing و factual detail می‌آید؛ نه glow.

### محدودیت‌های غیرقابل مذاکره

1. هیچ صفحه‌ای بیش از یک motion focal point در viewport ندارد.
2. grid محصول tilt، glare یا particle ندارد.
3. CTA خرید با decoration رقابت نمی‌کند.
4. نسخه mobile composition مستقل دارد.
5. هر asset دارای source/license/status است.
6. ادعاهای فروش/اصالت/گارانتی فقط با approval منتشر می‌شوند.
