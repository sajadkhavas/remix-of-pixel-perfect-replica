# اصول بصری قطعی KRONOS

1. **محصول قهرمان اصلی است.** UI قاب نمایش و ابزار تصمیم‌گیری است.
2. **Hierarchy پیش از animation تعریف می‌شود.** صفحه بدون motion نیز باید کامل و قابل فهم باشد.
3. **حرکت باید رابطه، جهت یا تغییر state را توضیح دهد.**
4. **یک حرکت اصلی در هر viewport.** elementهای متحرک نباید با هم رقابت کنند.
5. **اطلاعات خرید همیشه واضح است.** نام، قیمت، availability، variant و CTA نباید زیر افکت پنهان شوند.
6. **تزئین نباید CTA را تضعیف کند.** glow، grain، line و badge کنار CTA budget محدود دارند.
7. **Gold accent رنگ غالب نیست.** برای selection، key detail و emphasis محدود استفاده می‌شود.
8. **لوکس‌بودن از spacing، typography، photography و restraint می‌آید؛ نه صرفاً glow.**
9. **RTL فقط mirror نیست.** reading order، motion direction، icon direction، mixed script و logical spacing بازطراحی می‌شوند.
10. **Mobile-first interaction.** touch target حداقل 44×44؛ hover هیچ قابلیت یکتایی ندارد.
11. **کنتراست متن حفظ می‌شود.** muted text نیز باید خوانا باشد و اطلاعات ضروری muted نمی‌شوند.
12. **Focus یک state طراحی‌شده است.** focus-visible از hover متمایز و در همه backgroundها قابل مشاهده است.
13. **Reduced motion نسخه مستقل دارد.** فقط animation-duration:0 کافی نیست؛ composition ثابت و feedback جایگزین تعریف می‌شود.
14. **Loading ساختار صفحه را حفظ می‌کند.** skeleton نسبت‌ها، grid و action area را رزرو می‌کند.
15. **Error و empty dead-end نیستند.** علت، recovery و مسیر بعدی دارند.
16. **تصویر باید هدف داشته باشد.** فروش، مقایسه، توضیح ساخت یا داستان؛ asset تزئینی بی‌هدف حذف می‌شود.
17. **هر engine یک مالک دارد.** یک DOM transform فقط توسط یک engine کنترل می‌شود.
18. **Native behavior پیش‌فرض است.** smooth scroll/parallax enhancement اختیاری است.
19. **ادعاها evidence می‌خواهند.** badge و stats قبل از تأیید content/legal وارد production نمی‌شوند.
20. **Consistency به معنی یکنواختی نیست.** commerce، editorial و utility archetypeهای متمایز ولی هم‌خانواده دارند.
21. **Performance بخشی از art direction است.** media budget، LCP، CLS و input latency در acceptance visual بررسی می‌شوند.
22. **Product scale قابل مقایسه است.** framing و focal point در کارت‌ها استاندارد می‌ماند.
23. **رنگ تنها حامل معنا نیست.** icon، label، shape و text state را پشتیبانی می‌کنند.
24. **Brand assets با احترام استفاده می‌شوند.** wordmark و campaign material فقط با مجوز/منبع روشن.
25. **ظاهر production نباید داده placeholder را پنهان کند.**
