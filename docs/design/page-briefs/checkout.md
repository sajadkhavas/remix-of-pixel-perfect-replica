# Checkout — Visual Design Brief

## Goal
تکمیل امن خرید با حداقل ابهام.

## First impression
آرام، روشن و trustworthy.

## Visual hierarchy
Step/status → form → order summary → payment CTA.

## Primary component
Current step completion.

## Supporting components
validation، saved address، policy links.

## Image direction
فقط thumbnail کوچک محصول؛ no campaign.

## Motion direction
step transition 160–220ms؛ feedback فوری.

## Mobile behavior
single column، summary collapsible ولی totals/CTA visible.

## Trust requirements
SSL/payment/provider claims واقعی، fees قبل submit.

## Content density
متوسط و فرم‌محور.

## Accessibility considerations
labels، error summary، focus first invalid، no timeout surprise.

## Do-not-do list
dark decorative noise، hidden fees، ambiguous submit state.
