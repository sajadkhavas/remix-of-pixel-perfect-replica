# 404 — Visual Design Brief

## Goal
بازگرداندن کاربر به مسیر مفید.

## First impression
مختصر و human، نه شوخی مبهم.

## Visual hierarchy
Error label → explanation → search/primary destinations.

## Primary component
Search or return to shop/home.

## Supporting components
popular categories، report broken link.

## Image direction
optional small mechanical still؛ no heavy hero.

## Motion direction
none یا subtle once.

## Mobile behavior
centered but not excessive empty space.

## Trust requirements
no blame؛ preserve query/context where possible.

## Content density
کم.

## Accessibility considerations
focus heading/primary action، clear title.

## Do-not-do list
فقط 404 طلایی، dead-end، autoplay.
