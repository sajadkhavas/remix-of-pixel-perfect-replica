# Category — Visual Design Brief

## Goal
بیان تفاوت category و سپس ورود سریع به catalog.

## First impression
یک cue تصویری متمایز، اما commerce-first.

## Visual hierarchy
Compact category header → facets/result count → grid.

## Primary component
Product grid.

## Supporting components
short editorial intro، related guides.

## Image direction
category 3:4/hero crop اختصاصی؛ نه reuse packshot.

## Motion direction
header reveal اختیاری؛ grid ثابت.

## Mobile behavior
header کوتاه، filter drawer، alternate crop.

## Trust requirements
count از data؛ category claims factual.

## Content density
کم header، متوسط grid.

## Accessibility considerations
localized label، focus and filter semantics.

## Do-not-do list
full-screen campaign قبل محصولات، tint-only differentiation.
