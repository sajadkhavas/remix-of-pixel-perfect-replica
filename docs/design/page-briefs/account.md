# Account — Visual Design Brief

## Goal

مدیریت سفارش، مشخصات و ترجیحات.

## First impression

utility حرفه‌ای.

## Visual hierarchy

Account nav → current module → actions/status.

## Primary component

Module content.

## Supporting components

orders، addresses، profile، security.

## Image direction

کم؛ product thumbnails در orders.

## Motion direction

tab/module switch کوتاه.

## Mobile behavior

stack nav یا select، no horizontal cramped tabs.

## Trust requirements

security/session status و privacy links.

## Content density

متوسط-بالا.

## Accessibility considerations

current nav، form errors، session feedback.

## Do-not-do list

dashboard تزئینی، data بدون label، logout پنهان.
