# Contact — Visual Design Brief

## Goal
رساندن پیام و تعیین انتظار پاسخ.

## First impression
ساده و پاسخ‌گو.

## Visual hierarchy
Contact choice → form → verified details/SLA → map optional.

## Primary component
Contact form.

## Supporting components
phone/email/hours، FAQ links.

## Image direction
معمولاً لازم نیست؛ map/location فقط verified.

## Motion direction
form feedback only.

## Mobile behavior
single column، correct keyboard/input types.

## Trust requirements
آدرس/شماره/SLA واقعی و privacy note.

## Content density
کم.

## Accessibility considerations
labels، error summary، success receipt.

## Do-not-do list
placeholder production، social # links، map سنگین بدون نیاز.
