# Search — Visual Design Brief

## Goal
رسیدن سریع از intent به product/content مرتبط.

## First impression
task-focused و بدون تزئین.

## Visual hierarchy
Input → suggestions/recent → result groups → recovery.

## Primary component
Search field/combobox.

## Supporting components
Recent searches، popular categories، no-result suggestions.

## Image direction
thumbnail 1:1 کوچک و consistent.

## Motion direction
overlay open کوتاه؛ results بدون stagger.

## Mobile behavior
full-screen keyboard-aware، clear/close 44px.

## Trust requirements
availability/price در نتایج فقط live data.

## Content density
کم قبل query، متوسط بعد query.

## Accessibility considerations
combobox pattern، arrow/Enter/Escape، announcements.

## Do-not-do list
redirect fake به shop، autoplay suggestions، focus loss.
