# Compare — Visual Design Brief

## Goal

مقایسه تفاوت‌های واقعی 2–4 ساعت.

## First impression

فنی و خوانا.

## Visual hierarchy

Sticky product headers → differences first → grouped specs → actions.

## Primary component

Comparison matrix.

## Supporting components

remove/replace product، highlight differences.

## Image direction

1:1 same scale.

## Motion direction

column add/remove کوتاه؛ no drag requirement.

## Mobile behavior

دو ستون قابل scroll، first spec column sticky، differences toggle.

## Trust requirements

units normalized و source data.

## Content density

بالا اما grouped.

## Accessibility considerations

table semantics، headers associations، scroll affordance.

## Do-not-do list

رنگ تنها برای تفاوت، بیش از 4 محصول، specs حدسی.
