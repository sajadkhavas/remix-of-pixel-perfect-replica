# Cart — Visual Design Brief

## Goal
بازبینی دقیق سفارش و ادامه funnel.

## First impression
شفاف و بدون distraction.

## Visual hierarchy
Items → adjustments → totals/policies → checkout CTA.

## Primary component
Checkout CTA.

## Supporting components
quantity، remove/undo، delivery estimate، promo.

## Image direction
1:1 compact thumbnail.

## Motion direction
update feedback و drawer فقط.

## Mobile behavior
single column، totals نزدیک CTA، sticky CTA optional.

## Trust requirements
هزینه‌ها و ارسال محاسبه‌شده؛ no hard-coded free shipping.

## Content density
متوسط.

## Accessibility considerations
44px steppers، live totals، undo delete.

## Do-not-do list
cross-sell غالب، ambiguous fees، dead CTA.
