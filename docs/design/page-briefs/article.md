# Article — Visual Design Brief

## Goal
خواندن راحت و انتقال دانش factual.

## First impression
آرام، معتبر، human.

## Visual hierarchy
Category/title/deck → byline/date → hero → body → sources/related.

## Primary component
Rich text.

## Supporting components
TOC، captions، pull quote، product references disclosed.

## Image direction
16:9 hero + inline 4:3/macro با caption/source.

## Motion direction
none by default؛ media reveal optional.

## Mobile behavior
single column، 45–65 chars، sticky share حذف/compact.

## Trust requirements
sources، corrections date، author bio.

## Content density
low-medium.

## Accessibility considerations
semantic headings، alt/captions، tables responsive.

## Do-not-do list
parallax 400، line length طولانی، text overlay on busy image.
