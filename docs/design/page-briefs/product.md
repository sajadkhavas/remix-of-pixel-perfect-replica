# Product — Visual Design Brief

## Goal

کاهش عدم قطعیت و رساندن کاربر به تصمیم خرید آگاهانه.

## First impression

شیء دقیق، اطلاعات کامل، آرام.

## Visual hierarchy

Gallery → brand/name → price/availability → variant/CTA → evidence/specs.

## Primary component

Gallery + buy box.

## Supporting components

specs، delivery/return، reviews، related.

## Image direction

حداقل 7–8 view؛ 1:1 master؛ zoom detail.

## Motion direction

gallery transition کوتاه؛ add-to-cart state.

## Mobile behavior

swipe gallery، sticky price+CTA، details accordions.

## Trust requirements

serial/authenticity/warranty فقط policy-linked.

## Content density

متوسط بالا ولی progressive.

## Accessibility considerations

thumbnail buttons، live selected image، quantity labels.

## Do-not-do list

single image، lazy LCP، tilt، generic description، fake urgency.
