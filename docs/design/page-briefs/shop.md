# Shop — Visual Design Brief

## Goal
یافتن و مقایسه محصول با کمترین اصطکاک.

## First impression
catalog دقیق و خنثی، نه campaign شلوغ.

## Visual hierarchy
Title/result count → search/filter/sort → applied filters → grid.

## Primary component
Product grid و filter controls.

## Supporting components
Category chips، results summary، pagination/load more.

## Image direction
packshot consistent 1:1 و product scale ثابت.

## Motion direction
فقط feedback filter و image load.

## Mobile behavior
filter drawer، sort compact، 2-column grid با 44px actions.

## Trust requirements
قیمت/stock واقعی، بدون scarcity جعلی.

## Content density
متوسط-بالا با spacing 12–20px.

## Accessibility considerations
URL state، fieldsets، live result count، focus return.

## Do-not-do list
tilt grid، infinite shimmer، hidden filters، color-only status.
