# Faq — Visual Design Brief

## Goal

پاسخ سریع و کاهش تماس پشتیبانی.

## First impression

utility روشن.

## Visual hierarchy

Search/topic navigation → accordions → contact fallback.

## Primary component

Question/answer list.

## Supporting components

deep links، related policies.

## Image direction

none by default.

## Motion direction

accordion 160–220ms؛ content not delayed.

## Mobile behavior

full-width accordions، sticky search optional.

## Trust requirements

last updated، owner، policy consistency.

## Content density

متوسط.

## Accessibility considerations

button/expanded/region semantics، heading levels.

## Do-not-do list

answers مبهم، accordion nested زیاد، decorative hero بزرگ.
