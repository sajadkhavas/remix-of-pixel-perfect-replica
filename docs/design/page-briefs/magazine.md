# Magazine — Visual Design Brief

## Goal

ساخت اعتبار تحریریه و مسیر discovery محتوایی.

## First impression

editorial، spacious و informed.

## Visual hierarchy

Featured story → categories → latest grid → guides.

## Primary component

Featured article.

## Supporting components

topic filters، author/date، commerce links با disclosure.

## Image direction

4:3 editorial واقعی و consistent captions.

## Motion direction

یک feature reveal؛ grid static.

## Mobile behavior

single feature، 1-column feed، image 4:5.

## Trust requirements

byline، date، source، sponsored disclosure.

## Content density

متوسط.

## Accessibility considerations

heading hierarchy، full-card links بدون nested conflicts.

## Do-not-do list

packshot تکراری به‌عنوان editorial، fake expertise، marquee.
