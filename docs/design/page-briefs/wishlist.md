# Wishlist — Visual Design Brief

## Goal
مدیریت محصولات ذخیره‌شده و انتقال آگاهانه به cart.

## First impression
utility مرتب.

## Visual hierarchy
Count/status → grid/list → availability changes.

## Primary component
Saved product list.

## Supporting components
move to cart، remove، share optional.

## Image direction
product thumbnail/card consistent.

## Motion direction
selected state کوتاه؛ no celebratory loop.

## Mobile behavior
2-column یا compact list، bulk controls ساده.

## Trust requirements
stock/price changes timestamped where possible.

## Content density
متوسط.

## Accessibility considerations
pressed state، remove labels، empty recovery.

## Do-not-do list
قلب color-only، حذف بدون undo، unavailable product پنهان.
