# Photography Direction

## اصول مشترک

- هر تصویر یک وظیفه دارد: attract، identify، compare، explain یا prove.
- product reality بر mood مقدم است.
- رنگ dial/case/strap نباید با grading تغییر معنادار کند.
- reflections کنترل شوند اما material واقعی باقی بماند.
- source، photographer/vendor، license، model release و expiry در manifest ثبت شود.
- تصاویر برند ثالث فقط با مجوز یا press-use terms روشن.

## Hero

- **Framing:** ساعت 35–55٪ frame؛ نه cut ناخواسته crown/strap.
- **Lighting:** single key + restrained rim؛ detail در dial و case حفظ شود.
- **Background:** charcoal/material gradient، نه طلایی عمومی.
- **Negative space:** سمت inline-start برای text در RTL؛ mobile فایل مستقل.
- **Desktop crop:** 16:9/21:9 با focal point ثبت‌شده.
- **Mobile crop:** 4:5 یا 3:4؛ ساعت کمی بالاتر، text جدا از تصویر.
- **Do not:** چند ساعت کوچک، busy particles، baked-in text/logo، claim داخل تصویر.

## Product media set

هر SKU production-ready حداقل:

1. Primary front/three-quarter packshot
2. Side/crown
3. Back/caseback
4. Clasp/buckle
5. Wrist lifestyle با scale واقعی
6. Movement/macro در صورت visible/relevant
7. Packaging و included items
8. Scale reference یا dimensions diagram

**Primary packshot:** background خنثی ثابت، product scale ثابت، shadow نرم، 1:1 master حداقل 1600px.  
**Color accuracy:** white balance و reference chart در workflow.  
**Transparency:** فقط برای compositing مشخص؛ PNG سنگین به‌صورت default ممنوع.

## Category imagery

- هر category یک visual theme دارد، ولی lighting و grading هم‌خانواده می‌ماند.
- Luxury: macro material + refined wrist، نه فقط gold.
- Sport: environmental proof با readability محصول.
- Smart: interface/device context بدون تقلید campaign سازنده.
- Classic: architecture/texture و restrained wardrobe.
- category image نباید همان packshot کارت باشد.
- differentiation با subject/context، نه فقط tint سبز/آبی/طلایی.

## Brand/heritage

- workshop، tools، materials، architecture، archive و campaign فقط با source معتبر.
- logo/wordmark بدون تغییر و تنها با مجوز.
- heritage claim همراه caption factual و تاریخ/منبع.
- نمایندگی رسمی یا رابطه تجاری هرگز از layout استنباط نشود مگر تأیید شده باشد.

## Editorial

- human presence طبیعی و consent/model release ثبت‌شده.
- environment داستان را پیش می‌برد؛ ساعت همچنان identifiable.
- یک mood per story.
- caption شامل photographer/source و context.
- از stock generic «مرد کت‌وشلواری با ساعت» پرهیز شود.

## Technical capture notes

- Master: RAW/TIFF archive؛ delivery AVIF/WebP/JPEG.
- sRGB delivery؛ metadata حساس پاک‌سازی شود.
- sharpen per output size.
- mobile crop به‌صورت asset مستقل، نه CSS crop اجباری.
- focal point به‌شکل `{x,y}` درصدی در manifest.
